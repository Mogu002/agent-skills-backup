# Python Exercise Log

将 Python 学习过程中的练习题和解答结果持久化保存到 md 文件中。

## 存储位置

```
/Users/gaojing/.claude/projects/-Users-gaojing-Desktop-meituan/memory/python_exercises.md
```

## 触发条件

**只在用户主动说"记录"时执行**，不自动触发。

## 默认工作流

1. 尝试读取 `python_exercises.md`（不存在时在写入步骤中自动创建）
2. 从当前对话上下文中提取以下四项：
   - **题目描述**：本次练习题的题干或要求
   - **用户解答**：用户提交的代码或答案
   - **评判结果**：正确 / 错误 / 部分正确，附简短评语
   - **正确解析**：参考答案或知识点说明
3. 按以下格式追加写入文件：

```markdown
---

## 题目 N · YYYY-MM-DD

**题目**
（题目描述）

**我的解答**
\```python
（用户代码）
\```

**评判**
（正确 / 错误 / 部分正确）— （评语）

**解析**
（正确答案或知识点说明）
```

4. 写入完成后，告知用户"已记录到 python_exercises.md，当前共 N 道题"

## Gotchas

- 若对话中没有明确的题目或解答，先向用户确认要记录的内容，不要猜测或补造
- 题号 N 根据文件中已有条目数自动递增，读取文件时统计 `## 题目` 出现次数
- 不要修改已有条目，只追加
- 若用户说"记录"但本次对话没有出题和评判过程，提示"当前对话没有找到可记录的练习题"
