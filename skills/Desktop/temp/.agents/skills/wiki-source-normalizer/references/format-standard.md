# 标准化文档格式契约

本文件定义“系统化标准化文档”的**目标形态**：来源经过本 skill 处理后应满足的硬性约束。它描述结果长什么样，清洗怎么做见 [`cleaning-playbook.md`](cleaning-playbook.md)。

核心主张：**标准化只改变承载形式，不改变承载内容。** 下面每条约束都服务于“层级清晰 + 格式统一 + 内容忠实”。

## 1. 标题与层级

- **唯一 H1**：全文只有一个 `#` 一级标题，即文档标题。
- **标题即真实标题**：把“伪标题”升级为真标题——
  - 独占一行的纯粗体短语（如 `**背景**` 单独成行且领起一段）→ 视语义升为 `##`/`###`。
  - 中文枚举标题（`一、`、`二、`、`（一）`）若在原文承担章节作用 → 升为对应层级标题。
  - 行内的 `**粗体**` 前缀（如 `- **背景**：xxx`）保持原样，不要误升为标题。
- **不跳级**：`#` → `##` → `###` 逐级，不出现 `#` 直接跳到 `###`。
- **无重复 H1**：若原文有多个 H1，保留最贴合整篇主题的一个，其余按层级下沉。
- **缺标题时**：先读内容，起一个**中性、具体**的标题；不做标题党，不加入主观评价词。

## 2. 表格

- **简单表**（每格为短文本、无嵌套列表/图片/换行）→ 标准 GFM 表格。
- **复杂表**（含嵌套列表、图片、多行、rowspan/colspan）→ 标签化 bullet 块：`- **表头**：值`，保持可读且无信息丢失。
- **零残留**：输出中不得出现 `<table>/<tr>/<td>/<thead>/<tbody>/<colgroup>` 等标签。

## 3. 列表与行内格式

- 无序列表统一 `- `；有序列表用 `1. 2. 3.`。
- 嵌套用两空格缩进，层级正确。
- 行内：加粗 `**x**`、行内代码 `` `x` ``、链接 `[text](url)`；成对标记闭合，无 `****` 空标记。
- 代码块保留三反引号与语言标签（如果原文有）。

## 4. 图片与附件

- 有 http(s) URL 的图片 → `![alt](url)`，保留 alt 文本。
- 只有 token / 无有效 URL 的图片 → `_[图片: alt]_` 占位；**绝不编造 URL**。
- 附件下载链接 → `[附件下载](href)`；嵌入对象（多维表格/画板/录屏）→ 保留可读占位，如 `_[飞书多维表格嵌入: 标题]_`。

## 5. 噪声剔除

只删除**可复现判定的非内容外壳**：

- 面包屑 / 导航栏 / 侧栏目录 dump。
- 登录、cookie、订阅、footer 版权、“相关推荐”“猜你喜欢”区块。
- 重复出现的页眉页脚、页码。
- 零宽字符、追踪参数（URL 里的 `?utm_...` 等在不改变可达性的前提下可清理）。

**不删**：正文、脚注、作者原始注释、引用来源、数据表、更新记录表。拿不准 → 保留并在报告里标记“存疑保留”。

## 6. 空白与编码

- 折叠 3+ 连续空行为 1 个空行；清理行尾空格。
- 统一为 UTF-8；清理 BOM 和不可见控制字符。
- 文件以单个换行结尾。

## 7. 幂等与可入库

- **幂等**：再次运行确定性清洗，输出不变。
- **纯净正文**：不含 wiki frontmatter、不含 `source_id`/`source_hash`、不含本 skill 注入的元数据或批注。元数据在报告里单独给，不进正文。
- **下游兼容**：产出应能原样通过 wiki 入库前的自动清洗，不再触发二次结构改动。

## 快速对照

| 维度 | 达标 | 不达标 |
| --- | --- | --- |
| 标题 | 唯一 H1，层级不跳级 | 多 H1，伪标题散落 |
| 表格 | GFM 或标签化 bullet | 残留 `<table>` |
| 图片 | 真实 URL 或占位符 | 编造 URL |
| 内容 | 实质零丢失 | 被摘要/重排/删节 |
| 正文纯净度 | 无 frontmatter / 元数据 | 混入 source_id、批注 |
