## 二、典型剧本类型对照

| 剧本类型 | 通用描述 | 网约车 | 电商 | 内容平台 |
|---------|---------|-------|-----|---------|
| **竞对环境剧本** | 竞对关键指标变化 | 价格战 | 竞品大促 | 内容版权争夺 |

## 三、决策漏斗通用模板

### 单边业务（仅需求侧决策）

```
需求产生
  → [阶段1] 核心价值判断
      P(流失) = f(功能价值 vs 订阅成本, 用户价格敏感度)
  → [阶段2] 随机转化（基础转化率）
  → 成交 / 放弃
```

### 双边市场（异步弱耦合，如电商/内容）

```
需求产生
  → [阶段1] 核心决策变量判断（价格/质量/相关性）
      线性流失概率，按敏感度分层上限
  → [阶段2] 供给质量体验判断（时效/内容质量）
      Sigmoid 函数建模
  → [阶段3] 随机转化（基础转化率）
  → 供给库存/内容检查（是否有对应供给）
  → 成交 / 各类失败
```

### 双边市场（实时强耦合，如网约车/外卖）

```
需求产生（冒泡）
  → [阶段1] 价格判断（vs 竞对/心理价位）
  → [阶段2] 等待时间判断（Sigmoid）
      等待时间 = f(供需比)  ← 依赖本时段供需比（需三遍扫描）
  → [阶段3] 随机转化
  → 供给匹配（是否有在线供给接单）
  → 成单 ✓ / 价格流失 / 等待流失 / 无匹配流失 / 随机流失
```

## 四、TransactionContext 标准字段模板

```python
@dataclass
class TransactionContext:
    # 时间维度
    current_day: int
    hour: int           # 无时段概念的业务可省略
    time_slot: str      # 无时段概念的业务可省略

    # 地理/渠道维度
    region: str         # 城市/区域/渠道

    # 场景维度
    scene: str          # 交易场景类型

    # 需求侧维度
    demand_entity_id: str
    demand_lifecycle_stage: str      # 新/老
    demand_price_sensitivity: float  # 0-1
    demand_time_sensitivity: float   # 0-1（无等待概念可省略）

    # 供给侧维度（单边业务可省略全部）
    supply_entity_id: Optional[str] = None
    supply_type: Optional[str] = None
    supply_lifecycle_stage: Optional[str] = None
```

## 五、飞轮效应建模：供给侧收益指标 → 满意度 → 留存

不同业务的"供给侧收益指标"等价物：

| 业务 | 供给侧收益指标 | 满意度低 → 行为 | 满意度高 → 行为 |
|-----|-------------|----------------|----------------|
| 网约车 | IPH（每小时收入） | 司机离线/退出 | 新司机激活/兼职增频 |
| 电商 | 商家 GMV/ROI | 商家下架/减品 | 休眠商家重新上架 |
| 内容平台 | 万次播放收益 | 创作者停更 | 停更创作者复活 |
| SaaS | （平台侧固定，无此维度） | — | — |

**留存概率映射**（通用模板）：
```python
# 流失概率（满意度越低越高）
churn_prob = max(0, (THRESHOLD_LOW - satisfaction) / THRESHOLD_LOW) * MAX_CHURN_RATE

# 激活概率（满意度越高越高，仅当满意度超过高阈值时触发）
if satisfaction > THRESHOLD_HIGH:
    activation_prob = (satisfaction - THRESHOLD_HIGH) / (1 - THRESHOLD_HIGH) * MAX_ACTIVATION_RATE
```

## 六、均衡态关键指标参考范围

下表为各业务在"无剧本平衡态"下应达到的指标区间，偏离则说明 config 参数需要调整：

| 指标 | 合理区间 | 说明 |
|-----|---------|------|
| 需求侧日活跃率 | 配置值 ±10% | 不应单日暴涨暴跌 |
| 成交转化率（冒泡→成单） | 真实业务 ±5% | 与商分给出的业务基准对标 |
| 供给侧30天留存率 | >70% | 不应出现人口骤降 |
| 供给侧满意度 | 0.45~0.55 | 均衡态应在中性值附近 |
| 平台动量（指数移动平均） | 0.45~0.55 | 同上 |
| 新用户/老用户比例 | 与初始化配置匹配 | 5天内不应大幅偏移 |
