# Builder Skill

Use only for structure, schema, scripts, migration, and runtime entry changes. Use `.agents/skills/llm-wiki/SKILL.md` for daily knowledge work.

Before changing structure, read `操作文档.md`, `AGENTS.md`, and `index.md`. Preserve raw sources, keep the runtime boundary explicit, run `bash scripts/wiki.sh status` and `bash scripts/wiki.sh lint`, then update `log.md` and `todo.md`.
