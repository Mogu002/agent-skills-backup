# Reflect 评测（BWE-Reflect）

reflect 题目需在仪表盘 AI 侧边栏中**实际交互后**评测。所有子类统一按 **0/1** 二分制。

> 评测前先确认批次，并点击打开**产物 base 列**。截图一律**不带头部和侧边栏**（长图滚动截屏）。

## 黑盒测试注意事项

- **退群**：测试 reflect 黑盒时，如果在测试集群（如「BaseAI Test集群 路由FG」）中，需先退出。
- **上传日志**：每个评测 case 验证完成后，在侧边栏点击「上传日志」。
- **无产物题目**需手动评测：点开初始 base → 创建副本 → 在副本上评测。

## 子类与判分

reflect 的任务类型决定评测方式。**任务类型为「拒识」的不评（产研内部评测）。**

### 1. 合理推理 & 多轮协作

- 正常按与 BWE-Direct **相同标准**评测（见 [`direct-scoring.md`](direct-scoring.md)），**评两遍分别打 1 分、0 分**。
- 若明显仪表盘没创建：在侧边栏输入「用户指令」列内容，若 AI 触发交互/澄清，备注「触发了澄清」，并回复 AI「好的，请继续创建仪表盘」，再对结果截图评分。
- 若创建过程中再次失败：将失败部分（思考或错误内容）截图，记 **0 分**。

### 2. AI 共创（评一轮 + 快速校验）

| 步骤 | 操作 |
|-|-|
| 一 | 打开产物 base 列，侧边栏新建对话，粘贴用户指令，**截图保存** AI 返回部分。遇系统错误 → 截图判 **0 分**。 |
| 二 | 回复「方案一」或「好的，按你说的创建仪表盘」。遇需澄清/确认的，选择接受并确认。 |
| 三 | 判断生成的图表组件是否符合**最原始的用户指令** + 共创/确认/澄清要求；选择表、字段、筛选条件合理且满足布局基准 → 判 **1 分**。中途创建失败且无法通过回复「继续」恢复 → 截图判 **0 分**。需澄清/确认计划的，手动点击确认执行。 |
| 四（二轮） | 仅依据第一轮同学截图的 AI 问答记录评分。点开每个组件查看数据源、字段、筛选条件是否合乎逻辑，且满足布局基准。合理判 1 分，不合理判 0 分。 |

### 3. 澄清（评一轮 + 快速校验）

| 步骤 | 操作 |
|-|-|
| 一 | 打开产物 base 列，侧边栏新建对话，粘贴用户指令。 |
| 二 | **截图保存** AI 返回部分，并**勾选前两个选项**，点击确认执行。 |
| 三 | 判断生成的图表组件是否符合用户指令 + 共创/确认/澄清要求；创建组件合乎**所选选项**含义，选择表、字段、筛选条件合理且满足布局基准 → 判 **1 分**。中途创建失败且无法通过回复「继续」恢复 → 截图判 **0 分**。 |
| 四（二轮） | 仅依据第一轮截图的 AI 问答记录评分；点开每个组件查看数据源、字段、筛选条件是否合乎逻辑且满足布局基准。合理判 1 分，不合理判 0 分。 |

### 4. 用户意图优先（简单评测一轮）

| 步骤 | 操作 |
|-|-|
| 一 | 打开产物 base 列，侧边栏新建对话，粘贴用户指令。 |
| 二 | **截图保存** AI 返回部分，**不需要建仪表盘**。根据 Query 实际情况判分。 |

判分规则：
- **1 分**：符合用户要求，或触发系统安全拒识。
  - 例：按用户要求立刻开始计划，没有再共创或澄清（开始计划即可，无需点击创建仪表盘）。
  - 例：按用户要求给反馈，或再次确认后给正确反馈。
- **0 分**：不符合用户要求。
  - 例：用户要求「不要搭建/先给方案」，AI 未拒识并进入了生成仪表盘计划步骤。

## 通用收尾

- 评分后**追加仪表盘截图**。
- 0 分项写清原因；可复用 [`direct-scoring.md`](direct-scoring.md) 的错误标签与备注写法。
