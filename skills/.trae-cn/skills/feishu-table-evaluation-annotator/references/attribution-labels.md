# 归因标签说明

只使用下列固定标签。优先选择最贴近直接原因的标签；同一问题存在独立直接原因时可以多选。

| 标签 | 使用条件 |
|---|---|
| `表关联错误` | 关联字段指向错误表、关联关系或 lookup/rollup 依赖关系错误。 |
| `冗余产物` | 额外表、字段、视图、工作流等无助于用户目标，明显重复、冲突或增加负担。合理衍生不使用此标签。 |
| `需求项未实现` | query 的明确功能、对象、视图或能力完全缺失；若已实现但配置错误，优先使用更具体标签。 |
| `筛选 / 统计口径错误` | 筛选条件未配置、条件错误，或计数、汇总、统计范围与 query 不符。 |
| `公式错误或遗漏计算逻辑` | 公式缺失、引用错误、条件不全、单位错误、边界处理错误或计算逻辑遗漏。 |
| `排序 / 分组错误` | 排序键、方向、优先级或分组字段、分组层级不符合 query，或要求的排序/分组未配置。 |
| `工作流执行错误` | 工作流已经搭建，但动作执行失败、结果未落地或执行对象错误。 |
| `无 / 缺 mock 数据` | 用户明确要求样例数据，或关键功能必须依赖数据才能验证，但数据缺失或不足。 |
| `字段定义不合理` | 普通字段的类型、格式、精度、选项、语义或约束不能承载 query 要求。 |
| `模型拒识` | 生成或评测过程被模型直接拒绝，未产出可评测内容；不用于一般搭建失败。 |
| `触发澄清` | 本可依据 query 合理执行，却停在不必要的澄清环节，导致未完成产物。真正关键歧义不使用此标签。 |
| `环境问题 / bug` | 平台、权限、连接器或运行环境异常导致任务无法正确完成，且有相应证据。 |
| `首列定义不合理` | 多维表首列作为记录主标识时，字段语义、类型或可辨识性不合理。不要用它替代所有普通字段问题。 |
| `搭建失败` | 产物整体未创建、不可用或核心结构没有搭建成功，无法进入正常配置核验。 |
| `工作流逻辑bug` | 工作流的触发条件、分支、判断顺序或动作编排逻辑有误；区别于逻辑正确但实际执行失败。 |

## 标签选择优先级

1. 已有具体配置但配置错误：使用最具体的配置类标签。
2. 明确需求完全不存在：使用 `需求项未实现`。
3. 整体产物没有搭成：使用 `搭建失败`，不要把所有缺失项重复标成 `需求项未实现`。
4. 外部环境阻断：只有能确认环境异常时使用 `环境问题 / bug`，不能用它猜测未知原因。
5. 流程级异常：区分 `工作流逻辑bug`（设计逻辑错）与 `工作流执行错误`（执行结果错或失败）。

## 常见映射示例

- “到达时间”字段只有日期、没有具体时间：`字段定义不合理`。
- “按日期筛选”视图存在但没有筛选条件：`筛选 / 统计口径错误`。
- 用户要求住宿清单，但没有相应表或视图：`需求项未实现`。
- 住宿关联到了交通表：`表关联错误`。
- 自动化判断条件写反：`工作流逻辑bug`。
- 自动化逻辑正确但运行时报错、没有写入记录：`工作流执行错误`；若证据表明是平台故障，可追加 `环境问题 / bug`。
