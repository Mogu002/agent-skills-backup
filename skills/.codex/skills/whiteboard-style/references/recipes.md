# 13 种图的坐标配方（数值取自 `scripts/diagrams*.py`，可直接照抄）

每种图在 `assets/svg/` 有成品、在 `scripts/` 有可运行实现。**这些数字就是"1:1"的定义**：改内容时只动文案与数据，不动下面这些坐标。

## 骨架对照

| 图 | 骨架 | 一句话要点 |
|---|---|---|
| 架构 | 层级结构 | 4 层带，同层等宽，跨层只连主链 |
| 流程 | 线性叙事 | 左→右 6 步，回流只做一条 |
| 组织 | 层级结构 | 3 层树，同级等宽 |
| 泳道 | 泳道分组 | 4 列 × 3 行，实线主链 + 虚线交付 |
| 鱼骨 | 中心辐射 | 主骨水平，4 类原因斜插上下 |
| 漏斗 | 漏斗金字塔 | 5 级梯形，转化率写在层外 |
| 金字塔 | 漏斗金字塔 | 4 层收窄，右侧验收信号表 |
| 里程碑 | 时间序列 | 12 月等距轴 + 今天竖线 |
| 对比 | 矩阵画布 | 4 列卡片 + 结论区 |
| 柱状 | 数值比较 | 横向条 + 网格 + 样本量 |
| 折线 | 时间序列 | 双轴但刻度数对齐 |
| 树图 | 面积嵌套 | 面积 ∝ 数值，按剩余区域归一 |
| 飞轮 | 中心辐射 | 环形 5 节点 + 弧线箭头 |

## 1 架构 `1280 × 810`

```
层带：left=40, band_w=1200, band_h=138, gap=20, 首层 top=112
层标签：w=112, 距带左 12（层名 14/700 + "L1" 11/500 SUB）
节点区：area_x = 40 + 112 + 16, area_w = 1200 - 112 - 32
节点：node_gap=16, node_w = (area_w - gap*(n-1))/n, 卡高 = band_h - 44 = 94, 卡 y = 带 y + 22
连线：卡片底中点 → 带底 +4 → 下带 y-22，实线 1.3 + 箭头
底部：legend(40, 778) + note(980, 778)
```
4 层封顶；同层 3–4 个节点。L1 三卡、L2–L4 四卡时跨层宽度不同是允许的，层内必须等宽。

## 2 流程 `1320 × 620`

```
主链：x0=40, y0=170, 卡 176×118, gap=34（6 步占满 40→1250）
连线：前卡右边界 → 后卡左边界 -4，实线 1.6 + 箭头
分支：第 5 步下方 y0+210=380 处放 92 高卡（宽 = 176-20）
回流：虚线 5 4 从下游回上游，标签 10.5 SUB
```
6 步到顶，再多就拆"提交侧 / 执行侧"两张。回流只允许一条。

## 3 组织 `1240 × 700`

```

```

```
宽度：half = 300 × (该层占比/100)，梯形上下沿分别取本层与下层的 half
颜色：blue，最大流失层换 red（本包是第 3 级）
层内：阶段名 14/700 白 + "1,200 个" 11.5/500 白

```
转化率的分母永远是"上一层"，不是总量；文案里别把两者混用。

## 8 里程碑 `1560 × 640`

```
轴：axis_y=340, x0=150, x1=1440, step=(x1-x0)/11
月份：每点 4px 短线 + "N 月" 10.5 居中（y=axis_y+28）
节点：r=9；硬里程碑实心 + 白描边 2；检查点空心
卡片：218×112；上排 y=axis_y-176，下排 y=axis_y+66；卡片中心 = 节点 x；引线从节点 12px 拉到卡片边
今天：竖线 dash 6 5 + pill（红主题，y=104），位置按真实日期算
注脚：note(40, 594) 写排期口径
```
同一侧卡片中心距 = 2×step，所以 step ≥ 119 才放得下 218 宽卡；上下交替是硬要求。

## 11 折线 `1180 × 620`

```
绘图区：left=100, right=1040, top=170, bottom=470
左轴：0–100%，6 格（每 20%），标签 10.5 MUTED 在 left-14
右轴：0.70–1.00，6 格（每 0.06），标签 10.5 MUTED 在 right+14
主序列：实线 3px + 8% 面积填充 + 白底圆点 r=5 + 数值 11/600
次序列：虚线 2.6px "7 5" + 白底点 r=4.5
图例：legend(100, 520)；注脚：note(100, 570) 写一致性定义
```
两轴格数必须相同（都是 6 格），否则两条线的高低会被误读。

## 12 树图 `1180 × 640`

```
外层：x0=40, y0=150, w0=780, h0=440
内区：ix=50, iy=160, iw=760, ih=420, gap=10
切分：左列宽 = iw×0.38 满高；右侧 avail = ih-2*gap，
      横切高度 = avail × p/(右侧剩余占比合计)，再在末带内按占比竖切
子块：高度按子项占比切（560:352 = 61:39），标题 12.5/700 + 数量 11/400
右卡：rect(840, 150, 300, 300) 结构健康度，4 条结论
注脚：note(40, 620) 说明面积近似与归类口径
```
横切片高度按**剩余区域**归一，直接套总面积占比会把切片画大（这是本包修过的一个错）。

## 通用排版纪律

1. 同层等宽等高；跨层不等宽可以。
2. 一张图只有一个强色焦点，其余浅底 + 描边。
3. 卡片正文最多两行，第三行拆卡。
4. 图例 / 注脚 / 口径永远在最下方同一基线。
5. 数字必须自证：合计 = 分项和，占比同一分母，时间落在真实位置。
