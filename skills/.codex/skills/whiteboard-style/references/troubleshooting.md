# 画板排错表（`--check` 报警 → 修法）

一次真实跑批（19 张图）里的全部报警与处理，按出现频率排序。

## 1 textOverflow：文字超出节点

| 现象 | 原因 | 修法 |
|---|---|---|
| 架构图 5 处溢出 | 画布 760 宽放 4 张卡，中文标题 + 一句说明撑破 | 画布 760→810，卡片宽度按 `tw(最长行, 字号)+32` 重算 |
| 副标题比卡片宽 | 文案写太长 | 优先缩短文案到 ≤ 14 汉字，其次加宽卡片；不要缩字号到 10 以下 |
| pill 里的字贴边 | pill 宽度 = 文字宽 + 2×8 | 改成 +2×10，或 pill 字号 11→10.5 |

判定：`textOverflow > 0` 一律要改；这不是"看起来还行"的问题，换台机器渲染就会掉字。

## 2 nodeOverlap：节点重叠

| 现象 | 原因 | 修法 |
|---|---|---|
| 里程碑卡片相互压住 | 上/下排卡片中心距 < 卡片宽 | step ≥ 119 才放 218 宽卡；或减少节点、改上下交替 |
| 卡片被画布切掉一半 | 首个节点 x - w/2 < 0 | x0 从 150 起；必要时加宽画布 |
| 装饰线与卡片"重叠" | 刻意压在色块上的细线 | 可保留；但要确认压的是空白区，不是文字 |

判定：两张**卡片**重叠必须改；装饰元素与底色的重叠写入记录即可。

## 3 图能渲染但内容出错（`--check` 查不到）

| 现象 | 根因 | 修法 |
|---|---|---|
| 时间轴"今天"落在错误的季度 | 时间轴只画了上半年，标记位置照抄 | 时间轴按真实跨度画满（本次改成 12 个月），今天按真实日期算 x |
| 树图面积和标签占比不符 | 手算切片，横切片直接套总面积占比 | 横切片按**剩余区域**归一；子块按子项占比切 |
| 一张图出现两次同样的刻度 | 季度 + 月份双语义 | 只保留一种颗粒度 |
| 卡片文字全是同一句 | 按"层"写说明，不是按"节点" | 每个节点一句独立说明 |

## 4 DSL 相关

| 现象 | 根因 | 修法 |
|---|---|---|
| 图叠在别人的画板上 | 文档里画板顺序取错（SVG → Mermaid → DSL），token 序号错位 | 用 `--overwrite` 把被污染画板按原图源重建；下次按段落顺序核对 token |
| 卡片高度被截断 | `text` 节点写死 `height` | 容器 `fit-content`，文本高度 = 字号 × 1.4 |
| 图片显示占位 | `image.src` 写了 URL 或未上传到该画板 | `+media-upload --parent-type whiteboard --parent-node <board>` 换 media token |
| 连线消失 | connector 写进了 frame.children | connector 移到顶层 `nodes` |

## 5 Mermaid 相关

| 现象 | 根因 | 修法 |
|---|---|---|
| 整图为空 | participant 别名里带 `<br/>` | 改单行短词 |
| 思维导图层级错乱 | 用了 tab 缩进 | 统一 2 / 4 空格 |
| 甘特图刻度糊成一片 | 未设 `axisFormat` | 加 `axisFormat %m-%d` |

## 6 交付前 60 秒复查

```bash
for f in assets/svg/*.svg; do
  npx -y @larksuite/whiteboard-cli@^0.2.13 -i "$f" -f svg --check \
    | python3 -c "import sys,json;d=json.load(sys.stdin);c=d['check'];print(d['data']['metadata'].get('nodeCount'), c['errors'], c['warnings'], c['summary'])"
done
```

限制：Mermaid / DSL 的 `--check` 不检查文本溢出，必须看 PNG。
