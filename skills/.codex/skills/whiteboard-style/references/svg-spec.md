# SVG 规范（画板路线）

生成的目标只有一个：**飞书画板能解析、人能在画板上继续拖、任何字号下都不溢出**。

## 1. 画布与安全区

```python
c = Canvas(1280, 810, "标题（一句结论，26px）", "副标题（图例 / 口径，13px）")
```

- 画布尺寸按内容定死，不做响应式。常用宽度：1080 / 1180 / 1240 / 1320 / 1560。
- 标题基线 `(40, 52)`，副标题基线 `(40, 80)`，所以**内容从 y=100 开始**最安全。
- 外边距 40：左 40、右 40、底部留 40 给注释/图例。
- 一张图超过 1560 宽就该拆图，而不是把字缩到 10px。

## 3. 几何规范

- 卡片圆角 12，层带 / 大容器圆角 14，pill 圆角 = 高度一半（h=22）。
- 卡片内边距：标题距顶 24，正文行距 17；一行正文时卡片高 92–104，两行 118。
- 并列卡片间距 16–24；带间距 20；泳道行高 150（含 14 间隙）。
- 连线：主链路实线 1.6，依赖虚线 `dash="5 4"` 1.4，箭头统一 `marker-end="url(#arrow)"`。

## 4. 文本测量（决定溢出不溢出）

```python
def tw(text, size):   # 估算宽度
    return sum((1.0 if ord(ch) > 0x2E80 else 0.58) * size for ch in text)
```

规则：
- 卡片宽度 ≥ `tw(最长行, 行字号) + 32`。
- pill 宽度 = `tw(label, size) + 2 * padx`（padx 默认 10）。
- 中英混排按字符逐个累加，别用"字符数 × 字号"糊弄，英文会明显高估。

## 5. 能力边界（违反即渲染失败或掉样式）

禁止：`filter`、`mask`、`clipPath`、`pattern`、`radialGradient`、`foreignObject`、`textPath`、`<style>` 动画、`<script>`、外链 `<image>`。

允许且推荐：`<rect rx>`、`<circle>`、`<line>`、`<polyline>`、`<path>`、`<text>`、`<defs><marker>`、`<linearGradient>`（仅线性，配合 `fill="url(#id)"` 用浅色到白色）。

文字只能用 `<text>`，不要用 `<tspan>` 做复杂排版；需要换行就多写几个 `<text>`。

## 6. 校验动作

```bash
# 1) 结构检查：文字溢出 / 节点重叠 / 文字遮挡
npx -y @larksuite/whiteboard-cli@^0.2.13 -i x.svg -f svg --check

# 2) 渲染目检（PNG 只是中间产物，不是交付物）
npx -y @larksuite/whiteboard-cli@^0.2.13 -i x.svg -f svg -o x.png
```

判定标准：
- `errors > 0` 必须改，不接受"看起来还行"。
- `textOverflow > 0` 必须改：加宽卡片或缩短文案，不能靠缩字号。
- `nodeOverlap > 0` 逐个看：装饰线与卡片的"重叠"可保留，两个卡片重叠必须改。
- PNG 目检重点：半个箭头、被切掉的 pill、贴着边的图例、和标题打架的层带。
