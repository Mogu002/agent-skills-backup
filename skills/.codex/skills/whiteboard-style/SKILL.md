# 画板风技能（whiteboard-style）

本技能解决一件事：**把一段业务关系，变成一张坐标可控、文字不溢出、能被人在画板上继续改的图**。

它不负责数据分析图（占比、交集、漏斗转化率这种要跟表格对账的），那类走 `htmlbox-style`。

## 一、先判断走哪条路

| 信号 | 路线 | 原因 |
|---|---|---|
| 结构稳定、版式要精确、后续要人改 | **SVG**（本包 13 种图） | 绝对坐标，控制力最强，飞书能解析成可编辑节点 |
| 只有层级/时序，不需要精确摆位 | **Mermaid** | 语法成本最低，自动布局 |
| 需要真实图片、需要 Flex 等高排列、连线路由要锁定锚点 | **DSL(JSON)** | 原生 image / frame / connector 节点，SVG 表达不了 |
| 给出具体数量、占比、交集、转化率，且要和表格一致 | **转 htmlbox-style** | 画板不是数据图表载体 |
| 需要飞线地图、3D、粒子、渐变遮罩 | **转 htmlbox-style** | SVG 路线不支持这些特性 |

一句话：**能被"数"验证的图不进画板，只有"关系"的图进画板。**

## 二、创作流程（七步，别跳）

1. **四问定位**（30 秒，别写小作文）
   - 这张图回答谁的什么问题？
   - 读者视线先落在哪？（唯一视觉焦点）
   - 有几个层级 / 几条并列？超过 4 层、7 条就要拆。
   - 信息密度：卡片里要不要放副标题？
2. **选骨架**：层级 / 线性 / 时间序列 / 泳道 / 漏斗金字塔 / 矩阵 / 中心辐射 / 线框（见 `references/recipes.md` 顶部对照表）。
3. **选路线**：按上表；拿不准就用 SVG。
4. **产图源**：复制 `assets/svg/` 里最接近的一张当模板改，比从空白画布写起快 5 倍。
5. **本地校验**：
   ```bash
   npx -y @larksuite/whiteboard-cli@^0.2.13 -i x.svg -f svg --check     # 文字溢出 / 节点重叠
   npx -y @larksuite/whiteboard-cli@^0.2.13 -i x.svg -f svg -o x.png    # 渲染目检
   ```
   `--check` 的 `errors` 必须为 0；`warnings` 要逐条读，装饰性重叠可以留，文字压线不能留。
6. **落到画板**：文档里用 `<whiteboard type="svg" path="@x.svg">`（Mermaid 用 `type="mermaid"`）；已有空白画板用 `lark-cli whiteboard +update --input_format svg|mermaid|raw --overwrite`。
7. **回读**：写入后导出预览再看一眼。远端渲染和本地 PNG 可能不一样（字体、行高），这一步不能省。

## 三、硬约束（违反就会渲染炸或文字糊）

- 只用 `<text>` 写字，不要 `foreignObject`；不要 `filter / mask / clipPath / pattern / textPath`。
- 不要动画、不要脚本、不要外链图片；颜色写 6 位 HEX。
- 文字宽度自己算：**CJK ≈ 1.0em，拉丁 ≈ 0.58em**。卡片宽度给到 `tw(text, size) + 32` 以上才安全。
- 单卡片超过 3 行或 60 字就拆节点；流程图默认从左到右，别做成竖着的大块堆叠。
- 同层节点等宽等高；连线不穿节点；箭头方向与语义一致（请求实线、返回虚线）。
- 画布留白一次给够：左右至少 40px，标题区 100px，底部注释 40px 起。

## 四、样式令牌（要 1:1 就像素级照这个来）

```python
INK   = "#1F2329"   # 主文字
SUB   = "#646A73"   # 副文字
MUTED = "#8F959E"   # 注释
LINE  = "#BBBFC4"   # 连线 / 次级描边
# 主题三元组 (浅底, 主色, 深色文字)
blue   #F0F4FC / #3370FF / #1F4BD8
teal   #DBF5F0 / #14B8A6 / #0F766E
amber  #FEF1CE / #FF8800 / #9A5B00
red    #FEE3E2 / #F54A45 / #B3261E
purple #F0E9FF / #7F3BF5 / #5B21B6
gray   #F5F6F7 / #DEE0E3 / #4E5969
```

字号阶梯：标题 26/700 → 副标题 13/400 → 卡片标题 13.5–14/700 → 卡片正文 11.5/400 → pill 10.5–11/600 → 注释 11/400。

几何：画布宽 1080–1560（内容宽度定死，不要做响应式）；外边距 40；层带高 138、带间距 20；卡片圆角 12，层带圆角 14；pill 高 22、圆角 11；箭头 marker `refX=9, markerWidth=7`。

完整数值在 `references/svg-spec.md`，每种图的坐标配方在 `references/recipes.md`。

## 五、13 种图速查（都在 `assets/svg/` 有成品）

架构（1280×810，四层带）· 流程（1320×620，左→右主链 + 回流）· 组织（1240×700，三层树）· 泳道（1320×720，4 阶段 × 3 泳道）· 鱼骨（1320×720，主骨 + 4 类原因）· 漏斗（1240×700，5 级梯形 + 转化率）· 金字塔（1240×700，4 层）· 里程碑（1560×640，12 月轴 + 今天竖线）· 对比（1320×700，四列矩阵卡）· 柱状（1180×620）· 折线（1180×620）· 树图（1180×640，面积等比）· 飞轮（1080×720，环形 5 段）。

**图片展示不在 SVG 里**：它必须是真实图片节点，见 `assets/dsl/whiteboard_dsl_photo.json` 与 `references/dsl-spec.md`。

## 六、Mermaid 与 DSL 的边界

- Mermaid 只做 6 类：flowchart / sequenceDiagram / mindmap / gantt / pie / classDiagram。节点文字不超过 8 字，participant 别名不要带 `<br/>`。
- DSL 只做 SVG 表达不了的两件事：**图片卡片网格**、**锁锚点的原生连线**。`version: 2`、Flex frame、connector 放顶层、`height: "fit-content"`。
- 两者写入画板都要先 `--to openapi --format json`，再 `lark-cli whiteboard +update --input_format raw --source -`。

## 七、自查清单（交付前逐条过）

- [ ] `--check` errors = 0，warnings 每条都有理由
- [ ] 渲染 PNG 看过：无裁切、无压字、无空块、无半个箭头
- [ ] 同层节点等宽等高，跨层连线不穿节点
- [ ] 标题是一句结论，不是"XX 图"
- [ ] 图里的数字能自洽（合计、占比、时间位置）
- [ ] 时间轴有"今天"且落在真实位置
- [ ] 写进画板后导出预览再看一眼
