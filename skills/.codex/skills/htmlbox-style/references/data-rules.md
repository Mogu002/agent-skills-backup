# 数据自证规则（本项目 16 个返工点提炼）

按"最容易错"排序。每次都问自己一遍：**这张图的标题，读者能不能用图里的数字算出来？**

## 1 标题必须可由数据算出

| 错 | 对 |
|---|---|
| 「试用环节流失最大，注册到试用仅 38%」（38 是占访问） | 「访问到付费整体转化 19%，后两级各流失约一半」 |
| 「增速保持 30% 以上」（Q1/Q2 只有 18/23） | 「增速由 18% 升至 36%」 |
| 「API 与企业合同贡献 8 成收入」（178/200=89%） | 「贡献 89% 收入」 |
| 「自然流量占比下降 11pct」（45−34=11 ✓ 保留） | 一致的才留 |

做法：写完标题，先算一遍再落笔；有疑问就把结论写成区间或"约"。

## 2 占比的分母只有一种

- 堆叠柱：每根合计 100%。
- 漏斗：转化率 = 下一层 / 上一层，标题若引用则必须同分母。
- 饼/环：`{d}%` 由 ECharts 自己算，但要先确认数据总和与标题百分比一致（40/32/18/10 才能说"40%"）。
- 韦恩：分母是并集，七个互斥区相加 = 并集 = 100%。

## 3 汇总必须守恒

桑基/河流/旭日：上游之和 = 下游之和 = 总量。
本包改过一次上游（72+36+22=130 / 16+54=70）却忘改下游 132/68，读者一加就露馅。
**改了下游就回去改上游，改了一侧就两边重新核算。**

## 4 时间与位置是真的

- 时间轴上的"今天"按真实日期换算，不要落在"大概第三季度"。
- 预测段与实测段分开（虚线 / 浅色 / 明确标注 `E`）。
- 日历热力的周起点、时区不要再自己发明。

## 5 对比度（可读性也是正确性）

- 浅底（amber `#f59e0b`、teal `#14b8a6`、浅蓝 `#60a5fa`）上的数值 → 深色字（`#7c2d12` / `#083344` / `#1e3a8a`）。
- 白字只放深色（`#1e3a8a`、`#1d4ed8`、`#0284c7` 及以上深度）。
- 判定标准：4.5:1。拿不准就加粗加深色，别赌。

## 6 单位与刻度

- 轴名带单位（`万元` / `%` / `万次`），tooltip 的 `valueFormatter` 也带。
- 双轴两轴格数相同。
- 计数轴别用对数刻度做汇报图（读者会误读差距）。

## 7 留白与裁切

- `grid.right` 给足 60–90，否则最右的轴名/标签被切。
- 长标签用 `axisLabel.width + overflow:"truncate"`，不要让它自己溢出。
- 图例放底部（`bottom:4`）比顶部安全，顶部容易和标题抢空间。

## 8 示例数据必须标明

图里用的是示例数据时，副标题写清"示例数据"；换成真实数据时，标题、注释、结论一起改，不要只改数字。
