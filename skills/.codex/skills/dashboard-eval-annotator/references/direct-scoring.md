# Direct 评测标准（BWE-Direct）

适用：BWE-Direct 评测集，以及 reflect 的「合理推理 & 多轮协作」子类（复用本标准，评两遍分别打 1 分、0 分）。

核心立场：**阅读并比照 Query 内的全部用户要求**，逐条核对。任一项出错即「未通过」得 0 分；0 分项在备注逐条记录。

## 评测操作步骤

1. 确认自动化与初始 base 是否有权限。 
2. 按类型区分「新建 / 修改 / 多轮」，**对照原始 base 和答案**核对
3. 对答案中的组件**一个个点开查看配置信息**，看是否符合 Query，**不要改动原配置**。
4. 根据 Query 与本标准打分。
5. 写清备注和标签（最近产物有 AI 准度打分一并填写）。二轮只评 1 分项，与一轮人员不重复。

## 四个判分维度

| 维度 | 要求 |
|-|-|
| **指令遵循** | 生成结果需完全满足用户指令要求；确保仪表盘和组件准确完整的前提下可合理延展（配置无问题算正确），但不得偏离场景、误解或遗漏 Query 信息。 |
| **准确执行** | 完整匹配对用户指令的解析，在多维表格中无配置报错且可正常运行。 |
| **布局基准** | 仅「0-1 构建」或「要求全部重新排版」场景：仪表盘需无空隙紧密布局，符合阅读逻辑（F/Z）：指标卡/切片器 → 趋势图表 → 详细表格/透视表。 |
| **一票否决** | 任一项出错即判定该条「未通过」，得 0 分。 |

### 错误举例（判 0 分）

- 「创建赢单金额指标卡」→ 模型创建了商机总金额指标卡（指令理解错误）。
- 「仪表盘分为商机、客户、跟进记录三部分」→ 仅生成商机、客户两部分（指令遵循不全）。
- 「展示客户满意度趋势」→ 额外生成员工绩效趋势图（扩展偏离场景）。
- 「统计二月销售额」→ 筛选 >1/31 且 <2/28（正确应为 ≥2/1 且 <3/1，未准确执行）。
- 组件配置报错 / 无法显示数据（配置与执行错误）。
- 组件布局空隙、错位，切片器/文本组件置底等不符合阅读逻辑的排版（仅紧凑布局场景算错）。

## 例外情况（不扣分）

- 合理延伸组件算对；合理延伸筛选条件算对（如营业状态、时间年份）；筛选条件用切片器并应用到部分或全局组件算对。
- 所有组件不支持「图表选项」和「自定义配置」；组合图不支持左右轴和形状配置。
- 已有仪表盘新增组件（含多轮 0-1 构建），如无美化布局要求，**不检查排版**。
- 不支持文本、标题修改样式，只要文本内容正确填写或变更即算对。
- 不支持的组件：看板、日历、甘特图、画册、按钮、组合布局及其他插件。未使用它们、用替代组件实现核心需求且配置无误，算对。
- 时间筛选不含当日、多轮加组件排版混乱、无月度字段但选中日期、未要求重新紧凑布局时排版自由，均算对。
- 服务器时区导致的时间显示偏差算对；Query 先决条件里可加可不加的过滤条件，加了算对。
- 底表不具备对应计算能力（如逾期客户数）→ 标「需修改 Query」，**不判执行者错**。
- 录用人数≠入职人数、原仪表盘有空编号补充填空放指标卡、Query 未声明需检查的字段（如到访状态可加可不加），均算对。
- 因今年无数据导致图表无展示但统计/计算正确，算对。
- 指标卡用了百分比字段导致值为 0、1，把这种情况备注出来，算 1 分。

### 新建组件的筛选条件同步

模型在新建组件时会同步已有筛选条件。例：前四个指标卡都筛选了上月，新建组件自动加上「上月」（即使 Query 没要求），算对。

## 错误标签体系

0 分项**先勾选核心错误标签，再在备注逐条记录**。

### 核心错误标签

| 错误大类 | 标签 | 定义 | 示例 |
|-|-|-|-|
| 指令理解偏差 | 指令误解 | 对 Query 核心需求理解错误，结果与指令不匹配 | 赢单金额→商机总金额、扩展员工绩效趋势图 |
| 指令理解偏差 | 指令遗漏 | 未完整覆盖指令，缺失核心模块或功能 | 三部分仅生成两部分、诉求未完成 |
| 执行精度错误 | 筛选错误 | 时间/字段筛选逻辑错误、应用不完整或失败 | 二月范围错、仅筛选好评、筛选失败、时区外时间错 |
| 执行精度错误 | 字段配置错误 | 横轴/指标等字段选错，或未按要求聚合/取消聚合 | 月度横轴选日期、未取消横轴维度聚合 |
| 组件配置错误 | 组件显示异常 | 无数据、加载失败、展示不完整、配置报错 | 堆叠图无区域、文本组件加载中、多项未显示 |
| 排版逻辑错误 | 排版违规 | 紧凑布局场景出现空隙、错位、组件置底 | 组件错位、切片器置底、严重排版混乱 |
| 任务执行遗漏 | 任务未完成 | 核心需求未实现、数量不足或中途停滞 | 只生成一个仪表盘、任务没干完、啥也没做 |
| 严重逻辑错误 | 严重错误 | 题目理解错误、核心逻辑混乱、整体效果异常 | 未做变动比例、整体效果不对 |

### 特殊标签（非错误，用于特殊情形）

| 类别 | 标签 | 使用场景 |
|-|-|-|
| 特殊处理 | 底表能力不足 | 底表算不出 Query 要求的指标，需修改 Query |
| 特殊处理 | 需重评/重跑 | 需重新评测/重新执行，需指定负责人 |
| 合理情形 | 合理延伸 | 延伸组件、筛选条件且符合场景 |
| 合理情形 | 系统限制豁免 | 系统不支持的配置，核心功能达标 |
| 可优化情形 | 可优化 | 非核心错误、细节可调整，暂判错但不影响核心功能 |

## 标注使用说明

1. **0 分项**：先勾选对应核心错误标签，再在备注逐条记录具体错误（对应到标签、明确场景），避免模糊表述。
2. **标签优先级**：核心错误标签优先于特殊标签；多种错误时标注所有对应核心标签，再补特殊标签。
3. **豁免判定**：严格对照「例外情况」，确认属系统限制或合理延伸后标对应特殊标签，不判错。
4. **一票否决**：只要标注任意一个核心错误标签即判未通过得 0 分，无需叠加扣分。
5. **重评**：仅以第一个有效的仪表盘作为评测依据，标注重评需求并指定负责人。

## direct 特有给分

- 默认 0/1 二分制。
- **指令没执行完** 和 **没出现仪表盘** 的情况给 **-1**；其余按 0/1。
